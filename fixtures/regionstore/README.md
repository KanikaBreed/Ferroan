# Region store objects

`objects.db` is a SQLite region store seeded by [tools/regionstore-oracle](../../tools/regionstore-oracle/README.md). `objects.json` is the groups that store returns for region `11111111-1111-1111-1111-111111111111`. The `pin` field is the checkout that produced the dump. Pin8 (`c401bceecd`) regenerated it: the groups are unchanged; the database also carries `RegionStore` 48, the two indexes of #507.

The file holds one prim, two linksets, a prim with no shape row, a row whose structured value is not a map, a row that cannot be built, and one prim in another region.

- `aaaaaaaa-aaaa-aaaa-aaaa-aaaaaaaaaaa1` (`showcase`) is a single prim, so its link number stays 0. Its stored link number is ignored. The sit target is explicitly inactive. Stored flags keep physics and phantom; touch, money and allow-inventory-drop are cleared, and volume detect sets bit `0x4000`. Extra params stay `00aa`. The pseudo-CRC is 42.
- `bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbbbbb1` (`link-restore`) has children stored as link 3 then link 2. Those numbers are restored, so the parts come back as the root (1), `child-two` (2), then `child-three` (3). `child-two` has an explicit sit target with a zero offset, so the target is active.
- `cccccccc-cccc-cccc-cccc-ccccccccccc1` (`link-table`) has a missing stored number and a number past the group. The parts stay in table order: the root (1), `child-first` (2), then `child-second` (3). A further child whose dynattrs value is an integer is absent.
- `dddddddd-dddd-dddd-dddd-ddddddddddd1` (`no-shape`) has no shape row, so the shape is the default box, including the plywood texture bytes and a single zero extra-params byte. The sit offset is not zero and the active cell is null, so the target is active. Pay prices are 0. A stored pseudo-CRC of 0 is absent. The media URL is empty.
- A row whose id is not a UUID is absent. The other prims in the region still load.
- `ffffffff-ffff-ffff-ffff-fffffffffff1` belongs to region `22222222-2222-2222-2222-222222222222` and is absent from this dump.

The harness copies this file into the Ferroan region's per-run directory as `OpenSim.db`. A region whose id is not `11111111-1111-1111-1111-111111111111` keeps none of these groups. Local ids and parent ids are 0. Each of the eight structured payloads is dumped as the stored cell and as the value the load produced. `showcase` keeps a sanitised dynattrs map, one keyframe, a type-2 vehicle with its camera and motor-limit numbers filled, an inertia record, one named animation, a linkset whose cost is recomputed, two media faces and one materials override. `child-two` keeps an empty dynattrs map, an empty animation list, an empty materials override, a type-0 vehicle and a zero inertia record. Its short keyframe, unreadable linkset text and media whose type is not `sl` are absent. An animation sequence number is a clock and is absent.

`objects-mysql.json` is the same region's groups from MySQL RegionStore 71 at the same pin. The order is link number. `99999999-9999-9999-9999-999999999991` has every nullable column NULL, so those cells keep the defaults a new part uses: the name, text and description are empty, the scale is `[0, 0, 0]`, the sale price is 10 and the material is 3. A JSON null texture or extra-params cell is the default box texture and a single zero extra-params byte once loaded. The shape row is present, so this prim is not the default box. `no-shape` still has no shape row and is the default box. Showcase flags are `0x401` and volume detect is false. `showcase` items come back as `script`, `box`, `note`, and each item's parent id is the prim id. The experience cell that the SQLite seed stores as text that does not parse is the zero id in this seed. An orphan child whose parent is `abababab-abab-abab-abab-abababababab` is absent. The prim whose dynamic attributes are not a map, and the row whose id is not a UUID, are omitted from this seed because either one stops the MySQL load. `cargo xtask regionstore cross` checks this dump and removes the container.

`objects-postgres.json` is the same region's groups from PostgreSQL RegionStore 62 at the same pin. Each group comes back with its root first, then the children in stored link-number order. The stored link numbers are not applied. `88888888-8888-8888-8888-888888888881` is stored as the root of group `88888888-8888-8888-8888-888888888880` and loads as that group id, link 1, with the shape bytes kept, the default-box flag set and the raw cells empty. Its child loads as link 2. `child-second` loads as link 3. Showcase flags are `0x401` and volume detect is false. There is no keyframe column, so keyframe stays absent and the last attach point stays 0. `showcase` items come back as `note`, `script`, `box`, and each item's parent id is the prim id. The experience cell is a uuid, so the seed stores the zero id. A null required number or text, an inventory row that cannot be built, and a dynamic-attribute document whose top value is an integer are omitted from this seed because any one of them stops the PostgreSQL load. `cargo xtask regionstore cross` checks this dump and removes both throwaway containers.

Task inventory stays on the part and is not sent. `showcase` keeps three items in stored order (`note`, `script`, `box`): a null description, a creator id, a creator endpoint whose name becomes `Unknown User`, a creator endpoint and name, an experience id that does not parse (the zero id) and one that does. `child-two` keeps `mark`, whose creator id ends in a semicolon, so the name is `Unknown User`. `no-shape` keeps `blank`, whose creator id is empty, so the loaded id is the zero id. Every other loaded part has an empty item list. An item stored for the unbuilt prim, and one stored for the other region, are absent. `cargo xtask regionstore verify` reloads the file through the pin. Ordinary tests replay `objects.json` and do not start the oracle.
