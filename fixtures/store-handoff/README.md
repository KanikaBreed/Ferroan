# Persisted linkset handoff

These two full ObjectUpdate blocks are from the C# viewer circuit after Pin8 reopened the edited box and its linked mesh child. They use the local ID, persistent UUID and owner aliases in the [prim fixture map](../prim-updates/map.json). The box has scale (1.25, 1.5, 0.875). Its texture entry differs from the child's.

Run `cargo xtask live run store-handoff grid --physics basicphysics` under the shared live lock with a free port base and `UseSharedCompilation=false`. The harness installs the eight-part scene once. On C# it runs `edit scale box 1.25 1.5 0.875` and `backup`, waits for an independent SQLite reader to see the edit, then waits for the process to exit. A second C# home opens the committed file for the reference viewer. After that home exits, Ferroan opens the same file for a second viewer. Both viewers log out and wait for Presence and GridUser to clear.

The run's `grid/store-handoff/` directory contains all eight redacted reference blocks. The two linked parts are kept here. The other six blocks and the UUID map were byte-identical to the original prim fixture. An independent read of `prims.pseudocrc` on this store gave 1645670632 for the box and 1645675865 for the mesh. Attaching the restored box increments its value once. The offline replay checks every byte against the original linkset with those CRCs and the committed scale. Pin8 assigns new pseudo-CRCs to its backup copies, so these fields can differ between backups. The live comparison uses the same committed generation on both sides and checks the CRC bytes. It compares the original blocks after verifying the local and parent IDs against the stored linksets and mapping those two fields across circuits. Before redaction, each decoded block must re-encode to its captured bytes.

Reference: Tranquillity `c401bceecd1684832ae8ba86a31b5ee01a4ded7b`, `Scene.HandleEditCommand`, `SceneObjectPart.Resize` and `Copy`, `SceneObjectGroup.ProcessBackup` (3231–3252), `SQLiteSimulationData.StoreObject` (534–546), and `LLClientView.CreatePrimUpdateBlock`.
