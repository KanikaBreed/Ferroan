# Region store oracle

A .NET 10 console program that loads one region's prims from a SQLite or MySQL region store through the pinned region store. Rust tests compare those groups. The program is a C# exception in [D13](../../docs/DECISIONS.md): it has to run Tranquillity's own types. Nothing from that checkout is copied into this repository.

`cargo xtask regionstore generate` builds it against a task-owned clone of the pin and writes [fixtures/regionstore/objects.db](../../fixtures/regionstore/objects.db) and [objects.json](../../fixtures/regionstore/objects.json). `cargo xtask regionstore verify` rebuilds it and reloads that file. `cargo xtask regionstore cross` rebuilds it, reloads the SQLite fixture, starts a throwaway MySQL container, runs `mysql-seed` and `mysql-load`, compares stdout with [objects-mysql.json](../../fixtures/regionstore/objects-mysql.json), runs the gated `regionstore_` tests, and removes the container. Build products go under `.scratch/regionstore-oracle/`, not into the reference checkout. The commands need the .NET SDK and the pin checkout. They do not start a server or the live harness. Ordinary tests replay the committed SQLite dump and do not start the oracle or Docker.

```sh
cargo xtask regionstore generate
cargo xtask regionstore verify
cargo xtask regionstore cross
```

`seed <db>` creates the file and inserts the fixture rows. `load <db> <region-uuid> <pin>` writes one JSON object to stdout and records that pin. `mysql-seed <ado>` migrates a MySQL region store to version 71 and inserts the same rows, plus one prim whose nullable columns are NULL and one orphan child. `mysql-load <ado> <region-uuid> <pin>` writes that region's groups. The MySQL seed stores the zero id where the SQLite seed stores an experience id that does not parse, and it omits the prim whose dynamic attributes are not a map and the row whose id is not a UUID. Either of those rows stops the MySQL load. `cross` removes the container it starts. `bulk <db> <region-uuid> <count>` creates a store of that many single-prim groups, with no shape row, for a memory measurement. `cargo xtask regionstore bulk` runs it. It does not start a server. A row that cannot be built is absent. Texture entries and extra params of a stored shape stay the stored bytes. The eight structured payloads are dumped both as the stored cell and as the value the load produced. An animation sequence number is a clock and is absent. Each part's `items` list is the task inventory the load restored, in stored order, including an empty list. A null description is an empty string. The creator field is the identification string the load stores. An experience id that does not parse is the zero id. Items stay data.
