# Object permission fixtures

Run `cargo xtask permissions generate` to write [objects.json](../../fixtures/permissions/objects.json) and `cargo xtask permissions verify` to compare it with a fresh run. The runner builds the reference framework and links `Source/OpenSim.Region.CoreModules/World/Permissions/PermissionsModule.cs` from a clean scratch checkout at the revision in [REFERENCES.md](../../docs/REFERENCES.md).

Each row starts a fresh in-memory scene with one viewer and one phantom box with empty inventory. The actor, ordinary object owner, object group and estate owner are distinct test identities. The parcel and object use the same group. Ownership, membership, parcel flags, group powers and the prim's owner, group and everyone masks are explicit in the input. The prim's base mask is `AllEffective`. Masks and output flags are unsigned integers.

The oracle registers the real `DefaultPermissionsModule` on the scene. The viewer supplies its identity and cached group membership. Test services supply the same membership for UUID lookups, the account level, and the parcel at the test position. The scene graph registers the presence and prim. Pin8 computes effective masks, god status and permission decisions. The manager cases distinguish estate membership from the permission to act as an administrator. The level-200 cases distinguish account privileges from enabling god mode through the `automatic_gods` setting.

`clientFlagInput` is the flag word observed on entry to the module. `moduleClientFlags` records the module return value. `generateClientFlags` is the dispatcher result used by LLClientView, which intersects the incoming flags with each handler result. The other expected fields come from `Scene.Permissions.cs`. Edit, move and delete use the viewer overloads. Link uses the object UUID. Take-copy observes copying to inventory. Duplicate observes an in-world copy, which also requires permission to rez on the parcel. The table includes a pair with identical copy permissions and different parcel build flags.
