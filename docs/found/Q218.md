# Found while working: Q218

- 26 November 2026, Q218: The region has the account lookup `ModifySceneObject` needs (`ferroan-region` `grid.rs` `get_account`, `METHOD=getaccount`), but no `IGroupsModule.GetGroupRecord` and no `IUserAliasService.GetUserForAlias` client. `GroupsClient` only reads memberships. P2.0e4.5b and P2.0e4.8 need an `OwnerLookups` implementation with all three: the group record through the configured groups connector (remote and Local SQLite `os_groups`), and the alias through the `UserAlias` service connector. Until then, a load that answers "no group" and "no alias" clears every object group and sends every group-owned object to the default user.
- 26 November 2026, Q218: Pin8's stream constructor, `ArchiveReadRequest(Scene, Stream, Guid, options)` (`ArchiveReadRequest.cs` 295–317), does not read `default-user` and does not seed the zero group id as invalid, unlike the console path (201–293). A stream load asks the groups module about the zero group once. Q218 follows the console path. If a later item loads OARs from a stream, it should decide whether to copy that difference.
- 26 November 2026, Q218: Pin8 rewrites a part's last owner but not a task-inventory item's (`ArchiveReadRequest.cs` 834 and 855–872). An item's `LastOwnerID` from another grid stays as the archive had it. Ferroan copies this; the fixture shows it.
- 26 November 2026, Q218 review: `AddCreatorUser` makes no service call. In Pin8 it puts a Hypergrid creator's name into `UserManagementModule`'s cache, after checking the home URL with `IsLocalGrid` (`UserManagementModule.cs` 1223 on), so `UUIDNameReply` can serve that name. Ferroan's `GridNames` (`ferroan-region/src/names.rs`, Q84) has no such insert. The `OwnerLookups` implementation for P2.0e4.5b should add it.
- 26 November 2026, Q218 review: the console resolves `--default-user "First Last"` by name with `Scene.UserManagementModule.GetUserIdByName`. When no user is found it logs an error and does not load at all (`ArchiverModule.cs` 228–247). `OwnerOptions::new` takes a uuid, and no P2.0e4 row covers parsing the console option.
- 26 November 2026, Q218 review: Pin8's `TryUploadAsset` (`ArchiveReadRequest.cs` 1143–1157) calls `ModifySceneObject` on the same request, so the object load and the asset load share one set of caches. P2.0e4.8 should use the same `OwnerResolver` as P2.0e4.5b. Its object assets are read with `FromOriginalXmlFormat` or the coalesced reader (`SceneObjectSerializer.cs` 382–412), not XML2, so it must check that `from_original_xml` and `coalesced.rs` set `xml_creator_data` the way the XML2 reader does. Q218 covers only XML2.
