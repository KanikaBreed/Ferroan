# Found while working: Q220

- 26 November 2026, Q220: TB203. After a value that does not convert, `ExternalRepresentationUtils.ExecuteReadProcessors` steps past the parent's end tag when one follows. A bad value in the last element of a `landdata/` file stalls the OAR load for 60 seconds and then fails it; a bad last value in an access entry, a value with child elements, or another element in `ParcelAccessList` silently drops the elements after it. The same reader serves object, region-settings and other archive XML, so those readers likely share the failure; Q220 checked only `LandDataSerializer`. Ferroan reads in place (D139).
- 26 November 2026, Q220: TB204 (corrected by the review). `LoadParcels` leaves one temporary `LandObject` per parcel file on `OnFrame`, sharing the installed parcel's `LandData` until its first update. It runs the dwell update (on by default), resets `ParcelDwellTickMS`, and its `TriggerLandObjectAdded` can store the load-time land row and access list back over later edits. Ferroan does not reproduce it (D143).
- 26 November 2026, Q220: For a merge, P2.0e4.6b has to pass `load_parcels` each region parcel's bitmap as `LandData.Bitmap` holds it, region-sized. `ParcelMap` keeps only the cell map and the parcels, so it needs a way to rebuild one parcel's bitmap from its cells.
- 26 November 2026, Q220: Pin8's stream constructor (`ArchiveReadRequest.cs` 295–317) reads `merge` but not `merge-parcels`, `displacement`, `rotation` or the bounding options. A stream load with `merge` therefore never reads parcel files, and one without it uses the field initializers (no displacement, a 4096 m bounding box). Q220 follows the console path, like Q218.
- 26 November 2026, Q220: Parcels fall back to the estate owner, not to `default-user` (`ArchiveReadRequest.cs` 980 and 992), unlike objects. Ferroan copies this; the `default-user` option is not a parcel option.
- 26 November 2026, Q220: For P2.0e4.6b: install each `ParcelLoad` parcel once and keep no other object that can store it (D143). A store-swap compare after an edit and a restart would show TB204 on the C# side.
- 26 November 2026, Q220: For the row that ports dwell (`DefaultDwellModule`, `LandObject.OnFrame` 2091–2118): one updater per parcel, and the 0.9 change that fires `TriggerLandObjectAdded` stores the live parcel only. Pin8 after an OAR load splits dwell time between the live parcel and TB204's leftover object, so a dwell compare against a C# region that loaded an OAR will differ.
- 26 November 2026, Q220: The parcel reader parses into a tree (`ferroan_llsd::xml`), which drops comments and keeps undeclared entities as text (D139 lists the four differences). It should move to Q214's `XmlTextReader` model when that reader lands and is faithful.
