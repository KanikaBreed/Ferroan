# Found while working: Q226

- 26 November 2026: Pin8's PostgreSQL `StoreRegionEnvironmentSettings` (`PGSQLSimulationData.cs` 851–875) and `StoreTerrain` (623–658) each delete and insert on two connections. An insert that fails after the delete committed loses the row (TB205). Ferroan runs both writers' delete and insert in one transaction (D140).
- 26 November 2026: Whoever wires `StoreOnRegion` must serialise writes per region. Two stores of the same region at once can fail with 23505 on PostgreSQL and SQLite. MySQL `REPLACE` cannot.
