- 26 Nov 2026, Q61c2: `IsBannedFromLand` (`LandObject.cs` 873–901) returns false for an administrator and for `IsEstateManagerOrOwner`. The parcel map stores the estate owner passed to `open_parcels` and exempts that agent and the parcel owner. Estate managers stay on the simulation, and this frame has no administrator bit. A banned estate manager or administrator is omitted from a multi-parcel reply. `TaxFree` stays false: the estate row is not on the parcel map, so a tax-free region still applies ban lists. The SQLite `landaccesslist` table has no `Expires` column (`SQLiteSimulationData.cs` 1479–1486). Loaded bans are permanent. An in-memory expiry is still honoured. The inner test is `Flags == AccessList.Ban` (2). `AccessList.Both` (3) is not a ban on this path. `UseBanList` is 1024.
