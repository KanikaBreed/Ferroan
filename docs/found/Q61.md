# Found while working: Q61

- 25 November 2026, Q61: `LandObject.SendLandProperties` takes region flags from `EstateManagementModule.GetRegionFlags` (134–191). That method never sets `DenyAnonymous`, `DenyIdentified`, `DenyTransacted` or `DenyAgeUnverified`. `GetEstateFlags` (2360–2404) sets them, and the properties send does not call it. `LLClientView.SendLandProperties` (6812–6822, 6867) still reads the four bits. The comment at 6813–6820 says the estate module folds the identified and transacted bits into those flags. The four region-deny fields in the event are false. Viewers enforce the fields they are sent, so Ferroan matches `GetRegionFlags` (TB152, D108).
- 25 November 2026, Q61: `crates/ferroan-region/README.md` says Pin8 reads the unsigned power mask for ParcelProperties. The send path (`LandObject.SendLandProperties` 490–525, `LLClientView.SendLandProperties` 6757–6893) does not. `UpdateLandProperties` (`LandObject.cs` 528) does, through `CanEditParcelProperties`, and that editor stays in Phase 5 (D39). A multi-cell `ParcelPropertiesRequest` skips a parcel the requester is banned from (`LandManagementModule.cs` 1629). Q60c1's membership list is that ban test, and the overlay. It does not change an unbanned viewer's property bytes.
