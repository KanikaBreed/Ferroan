# Found while working: QR22

- 2026-11-24, QR22: At pin `c401bceecd`, a null or zero scene-group id on PostgreSQL throws and the region gets no objects. On MySQL a null or zero id is an orphan and that prim is not loaded. On SQLite a null id skips that prim. Ferroan leaves a null or zero group id out and keeps the other prims (TB77, D62). When no prim's id equals the group id, PostgreSQL rewrites the first part's id to the group id. MySQL leaves those children out. Ferroan leaves them out on both (TB78, D63). No viewer needs the region empty or the promoted id. There is no live compare. The object XML writer still writes AllowUnsit and ScriptedSitOnly as constants; QR23 owns that writer.
