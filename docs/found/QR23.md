# Found while working: QR23

- 2026-11-25, QR23: The object XML reader in `crates/ferroan-scene/src/xml_read.rs` ignores `AllowUnsit` and `ScriptedSitOnly`. Reading a part with unsitting disabled and scripted sitting required restores the opposite defaults. At Pin8 `c401bceecd`, `SceneObjectSerializer.ProcessAllowUnsit` and `ProcessScriptedSitOnly` restore the two supplied values. QR23 covers writing these fields.
- 2026-11-25, QR23: Local `cargo xtask regionstore cross` passed the SQLite oracle and then failed at `mysql-seed` with “Couldn't connect to server”. The readiness check pings a local socket inside the container while the C# seed connects over TCP. The Docker image can serve its bootstrap socket before opening the TCP listener. The PostgreSQL probe also defaults to a socket. The passing validation run used a local shim to make the probes use loopback TCP. The readiness probes in `xtask/src/regionstore.rs` still use the sockets.
- 2026-11-25, QR23 review: A terrain-triggered save at Pin8 `c401bceecd` writes the full settings row, including clamped elevations, zero legacy sun values and a zero id for a null covenant (`SQLiteSimulationData.fillRegionSettingsRow`). Ferroan persists the resolved textures and cache id. The stored representations of the other columns can differ after a save without changing the handshake.
- 2026-11-25, QR23 review: Grid registration in `crates/ferroan-region/src/grid.rs` sends `access=13`. With stored maturity 2 the viewer handshake announces 42 while Robust registers the region as PG. At Pin8 `c401bceecd`, `GridRegion(RegionInfo)` in `Source/OpenSim.Services.Interfaces/IGridService.cs` registers `RegionInfo.AccessLevel`. The registration mismatch predates QR23.
