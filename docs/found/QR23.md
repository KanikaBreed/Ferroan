- 2026-11-25, QR23: The object XML reader in `crates/ferroan-scene/src/xml_read.rs` ignores `AllowUnsit` and `ScriptedSitOnly`. Reading a part with unsitting disabled and scripted sitting required restores the opposite defaults. At Pin8 `c401bceecd`, `SceneObjectSerializer.ProcessAllowUnsit` and `ProcessScriptedSitOnly` restore the two supplied values. QR23 covers writing these fields.
- 2026-11-25, QR23: Local `cargo xtask regionstore cross` passed the SQLite oracle and then failed at `mysql-seed` with “Couldn't connect to server”. The readiness check pings a local socket inside the container while the C# seed connects over TCP. The Docker image can serve its bootstrap socket before opening the TCP listener. The PostgreSQL probe also defaults to a socket. For validation the second run used the same probes over loopback TCP.
