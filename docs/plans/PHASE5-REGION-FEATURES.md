# Phase 5 plan, part 2: region features

Planning note for the manager. This file is the map. It does not add rows to [TASKS.md](../../TASKS.md) or [WORK_QUEUE.md](../../WORK_QUEUE.md). The ids below are proposals. Queue ids are allocated when the rows are accepted.

**Gate** ([PLAN.md](../PLAN.md)): OAR and IAR round trips match the C# server, and the feature checklist reaches parity. [PLAN.md](../PLAN.md) measures effort in person-months, at 3,000 to 6,000 lines of C# per person-month. The whole of Phase 5 is 24 to 47 person-months. This file is the region-features half of that sentence: NPCs and bots, linkset data, Experiences, map tiles, dynamic textures, saving an archive, IAR, media, sound, remote admin, and monitoring. Land, parcels, estates, groups in the region, inventory transfer and the money module are the land, estates and groups plan. This file cites that plan's row ids, including its lettered splits. It does not estimate that half.

**Scope here:** NPCs and bots (the NPC module and the region side of its `os` and `bot` functions), linkset data, Experiences on the region, map tiles (generation, the region's upload client, the world-map blocks), dynamic textures, OAR and IAR beyond Phase 2's load (save oar, load and save iar, the archive formats and options, assets in archives), media (parcel and prim media, the region side of media on a prim), sound (loop, attached, preload, trigger, collision), remote admin (the XML-RPC plugin and its methods), and monitoring (the stats the scene can count, the monitor module, sim stats sent to viewers).

## 1. What Tranquillity does today

### NPCs and bots

An NPC is a root presence with `PresenceType.Npc` and an in-memory circuit. `NPCModule` turns on only when a `[NPC]` section exists and `Enabled` is true, and the default of that key is true (`NPCModule.cs` 54–58). The shipped `RegionServerDefaults.ini` has the section and leaves `Enabled` commented (2810–2812), so both the NPC module and `BotManager` are on. A missing section leaves both off. `BotManager` uses the same test (`BotManager.cs` 184–189) and disables itself when `INPCModule` is missing. With the module on, `AllowNotOwned`, `AllowSenseAsAvatar`, `AllowCloneOtherAvatars` and `NoNPCGroup` default true (`NPCModule.cs` 60–74). `MaxNumberNPCsPerScene` starts at 40 (`NPCModule.cs` 48). The cap test is `m_MaxNumberNPCperScene > 0` (`NPCModule.cs` 162–166). A cap of 0 is unlimited, and so is a negative cap. `NoNPCGroup` true means the module does not force the title `- NPC -`.

`BotManager` starts a navigation poll of 500 ms when it is enabled (`BotManager.cs` 162, 191–195) and registers `IBotManager`. Arrival is a horizontal distance of 1.5 m (`BotManager.cs` 163, 780). A point the bot has not reached after 60 seconds, or after `BOT_MOVEMENT_TELEPORT_AFTER` when that is set, is a teleport (`BotManager.cs` 165–167, 636). Outfits live in memory (`BotManager.cs` 145–151, `SaveOutfitToDatabase` 1594–1624, `SaveBotOutfit` 1628–1648, `ChangeBotOutfit` 1666–1684). Persistence stores the bot's own `appearance_data` and respawns with no outfit name (`BotPersistenceManager.cs` 206, 1094–1099).

Persistent bots need a `[BotPersistence]` section. The section is absent from the shipped defaults, and a missing section leaves persistence off (`BotPersistenceManager.cs` 121–126). When the section exists, `Enabled` defaults false (129). `DatabaseFile` defaults to `botpersistence.db`, then the region id is inserted, so the file is `botpersistence_<region id>.db` (136–152). Caps default to `MaxPerParcel` 10, `MaxPerOwner` 15 and `MaxPerRegion` 50. `DefaultTTL` is 604800 seconds, `SeparateAgentPool` false, `PositionSaveInterval` 60, `CleanupInterval` 21600 and `RespawnRate` 2 (136–144). Error codes are 0 and −1 through −7 (`BotPersistError` 33–43). The table is `persistent_bots` (187–220). `RegionLoaded` replaces the one `m_persistence`, loads bots, starts timers and registers console commands (`BotManager.cs` 157, 206–226). `clear persistent bots` takes an optional owner id (1829–1833). A create that does not ask for persistence does not survive a restart.

What another viewer sees is the ordinary avatar path: an `ObjectUpdate` for the presence, `AvatarAppearance`, `AvatarAnimation`, and `ChatFromSimulator` when the NPC speaks. The NPC client does not open a UDP session and does not receive caps. `SendChatMessage` and `SendInstantMessage` on that client raise events for scripts. Coarse locations include the NPC. World-map green dots skip `IsNPC` (`WorldMapModule.cs` 431–432). The shipped `[Map]` comments `ShowNPCs` and does not set the key (544–545).

`MoveToTarget` returns false when the presence is seated or sitting on the ground, and otherwise calls the presence move (`NPCModule.cs` 246–266). Sit calls `HandleAgentRequestSit` with a zero offset (329–340). Say, shout and whisper call the NPC avatar (`NPCModule.cs` 294–360). The avatar trims the text, drops an empty channel-0 message, and returns when `OnChatFromClient` is null (`NPCAvatar.cs` 255–262). Channel 0 then reaches viewers at the normal distances and every channel reaches a script listen. `CheckPermissions` allows a zero caller, an unowned NPC, the owner, or a caller id equal to the NPC id (`NPCModule.cs` 451–486). `Touch` grabs a part that has a touch handler (`NPCAvatar.cs` 168–194). `GiveMoney` posts a money transfer (163–166). `Broadcast` is chat type broadcast on channel 0 (158–160).

YEngine's `osNpc*` calls `INPCModule`. Phlox's `osNpc*` and `bot*` call `IBotManager`, which then calls `INPCModule`. The 4-argument create differs by door: YEngine follows `AllowNotOwned`, and the Phlox `osNpc` form passes owned. That difference is a script body. P4.S17 and P4.S26 own the bodies. This plan owns the two modules those bodies call, the presence, the packets and the persistence file.

### Linkset data

The store is on the root prim. There is no packet and no capability. The only limit is `LINKSETDATA_MAX`, 131072 (`LinksetData.cs` 15). Cost is the UTF-8 length of the key, plus the value when the value is not whitespace, plus `max(password length, 32)` when a password is set (`LinksetData.cs` 440–457).

`AddOrUpdateLinksetDataKey` (127–157) returns 1 when `BytesFree` is already at or below 0 (`LinksetDataOverLimit` 307–312), 2 for a blank key, −1 for a bad password, and 2 when the value is unchanged. Otherwise it subtracts the old cost, stores the new entry and adds the new cost, and returns 0. The limit test runs before the old cost is removed. `LinksetDataAccountingDelta` (385–391) lets `BytesUsed` pass 131072 and then clamps `BytesFree` at 0. `DeleteLinksetDataKey` (170–194) returns −1 for a blank or missing key, 1 for a bad password and 0 on success. `CheckPassword` (417–421) accepts any supplied pass when the stored password is empty. The comment above that line describes the opposite. The code is what a script observes. P5.48 matches the code.

The region store column is `prims.linksetdata`, one JSON blob. Empty is SQL NULL. `SerializeLinksetData` returns null when the store is empty. Object XML writes a `LinksetData` element from that same JSON when it is non-empty. Ferroan already parses that JSON on the part (`crates/ferroan-scene/src/payloads.rs`, `LINKSET_MAX`). The live key-value calls, the `linkset_data` event and the merge on link are not that parser.

A link copies the incoming root's keys into the destination. Destination keys win, and the source store is cleared (`LinksetData.cs` 315 onward). No `linkset_data` event is posted for that merge. The script event and the LSL status integers are P4.S4. This plan is the store those calls read and write, including the password, the byte account and the prim column.

`LinksetData.cs` has no licence header. The licences section states the rule for that file and for the other headerless files this plan cites. The existing parser keeps both notices already recorded on that port.

### Experiences

The region module is off unless `[Experience]` exists and `Enabled` is the string `true`. The default of that key is `false` (`ExperienceModule.cs` 47–57). `ExperienceCreators` defaults to `EstateManagersAndRegionOwners` (61). The module is shared and keeps one `Scene`, the last region added (`ExperienceModule.cs` 33, 68–73). `RemoveRegion` assigns its parameter to null (83–90).

When it is on, every new client, including a child agent, loads that agent's permission rows (`OnNewClient` 113–116), and the module registers these caps (`ExperienceModule.cs` 131–165): `GetExperiences`, `GetAdminExperiences`, `GetCreatorExperiences`, `AgentExperiences` (GET and POST on one URL), `GetExperienceInfo`, `IsExperienceAdmin`, `IsExperienceContributor`, `RegionExperiences`, `UpdateExperience`, `GetMetadata`, `GroupExperiences`, `FindExperienceByName`, `ExperienceQuery` and `ExperiencePreferences` (GET, PUT and DELETE, 169–180). There is no viewer key-value cap. Key-value is a script call that reaches the service.

Write caps are `UpdateExperience` (150), `AgentExperiences` POST (141–145, acquire gated by `CanAcquireExperience` 342–351, with the `purchase` key emitted only for a permitted agent at 330–331), `ExperiencePreferences` PUT and DELETE (169–180, 240–257) and `GetMetadata` (151). `ExperienceQuery` is registered at 159. `ExperienceQueryGetHandler.ProcessRequest` (888–905) answers true for every requested id.

Entering a parcel runs `UpdateScriptExperiencePerms` (`ExperienceModule.cs` 75–81, 656–698). A block does the same from `SetExperiencePermissions` (366–386). A grant that no longer stands has `PermsGranter` and `PermsMask` cleared, posts `experience_permissions_denied` with reason 4 when the agent blocked the experience and reason 17 when the land no longer allows it, and detaches an attachment whose experience is no longer allowed (`EndExperienceGrant` 701–718, detach 691–696).

The region client is `ExperienceServicesConnector` (`OpenSim.Services.Connectors/Experience/ExperienceServicesConnector.cs`). The reads are 55–315 (`FetchExperiencePermissions` through the group-experience reads). The key-value calls are 317–519, each with `METHOD=accesskvdatabase` (`GetKeyValue` at 317). `RemoteExperienceServicesConnector` (`ServiceConnectorsOut/Experience/RemoteExperienceServiceConnector.cs` 37–40) loads when `[Modules] ExperienceServices` is `RemoteExperienceServicesConnector`. `LocalExperienceServicesConnector` (`LocalExperienceServiceConnector.cs` 38–54) loads when `[Modules] ExperienceService` is `LocalExperienceServicesConnector`, then loads the in-process service named by `[ExperienceService] LocalServiceModule`. `Grid.ini` 29 and `GridHypergrid.ini` 35 select the remote connector. `GridCommon.ini.example` 246–252 points `ExperienceServerURI` at Robust. `Standalone.ini` 26 selects the local connector, and 134–135 point `LocalServiceModule` at `ExperienceService`. That service is MySQL only. Tranquillity has no SQLite experience store, so a standalone process still needs MySQL for the in-process service. Robust leaves `ExperienceServiceConnector` commented (`GridServer.ini.example` 136). The region connector in the shipped grid and standalone includes is on. The caps module stays gated by `[Experience] Enabled`. [P1.12](../../TASKS.md) owns the Ferroan connector and the Ferroan store. P1.0 and P1.1 are done. P1.12 is still to do. The region rows call Pin9's service through this client. They do not build a second store, and they do not wait on P1.12. P5.51 is the harness change that enables the commented Robust line on MySQL.

Estate allow, key and block lists are P5.16d. This module reads them (`GetEstateAllowedExperiences` 632–645). A parcel experience allow entry has flags 8 (`ACCESS_LIST_ALLOWED` 649). A parcel experience block entry has flags `0x10`. Both are P5.4b. The estate experience-list delta is `handleEstateExperienceDeltaRequest` (`EstateManagementModule.cs` 1281–1298, subscribed at 2346) and `SendEstateExperienceLists` (1305–1309). That delta is P5.16d. This file does not schedule it.

### Map tiles and the world map

Four surfaces. A viewer asks for blocks, items and a name search over UDP. The region stores a terrain JPEG and a parcel JPEG as texture assets and copies their ids onto the grid region. A separate map-image service stores zoomed JPEG files. Hypergrid grids load `HGWorldMapModule` in place of `WorldMapModule`.

`WorldMapModule` enables when `WorldMapModule` equals `WorldMap`, and that key defaults to `WorldMap` (`WorldMapModule.cs` 142–144). `BlacklistTimeout` defaults to 600 seconds, stored as milliseconds (146–147). `ExportMapAddScale`, `ExportMapAddRegionName` and `LocalV1MapAssets` are read beside it (149–153). Console commands are `export-map` and `generate map` (173–181). `OnRegionUp` drops that region from the blacklist (1690–1697). The `MapLayer` cap is POST only and answers one layer, image `00000000-0000-1111-9999-000000000006`, right and top 30000 (272, 284–310). `AddHandlers` registers `regionImage` plus the region id with the dashes removed, on `index.php?method=` (227–235).

`MapImageModule` enables when `MapImageModule` equals `MapImageModule`, and that key defaults to `MapImageModule` (`MapImageModule.cs` 174–176). It reads `TextureOnMapTile`, code default false (120–121). True selects `TexturedMapTileRenderer`. False selects `ShadedMapTileRenderer`. When the scene has entities it always draws prims through `DrawObjectVolume` (130–132). `Warp3DImageModule` enables only when the same key equals `Warp3DImageModule` (`World/Warp3DMap/Warp3DImageModule.cs` 87–89). That module reads `DrawPrimOnMapTile`, `TextureOnMapTile`, `TexturePrims`, `TexturePrimSize` and `RenderMeshes` (94–106). The shipped `[Map]` comments both generator names and leaves the legacy module selected (503–508). The keys at 521–533 (`DrawPrimOnMapTile` true, `TextureOnMapTile` true, `TexturePrims` true, `TexturePrimSize` 48, `RenderMeshes` false at 533) are the Warp3D keys. With the legacy module selected, `TextureOnMapTile` true is the one of those keys the legacy generator reads, so the stock file uses the textured renderer. `MapColorWater` defaults to `#1D475F` (`TexturedMapTileRenderer.cs` 159, `ShadedMapTileRenderer.cs` 54). `MapColor1` through `MapColor4` default to `#A58976`, `#455931`, `#A29A8D` and `#C8C8C8` (`TexturedMapTileRenderer.cs` 160–163). The textured renderer decodes terrain textures as JPEG 2000 (199–216).

`GenerateMaptiles` defaults true. `OnlyGenerateIfMissing` defaults false. `MaptileRefresh` defaults to 0, which starts no timer (`Scene.cs` 1086–1100). When generation is off, a non-zero `MaptileStaticUUID` becomes `TerrainImageID` (1103–1116).

`AddRegion` copies `RegionSizeX` into `m_regionSizeY` (`WorldMapModule.cs` 167–168). Items test that field (385) and the map export uses it (1279). `MapBlockFromGridRegion` (1110–1138) writes the block's `SizeX` and `SizeY` from the grid region's own `RegionSizeX` and `RegionSizeY`. The grid record carries `sizeX` and `sizeY` (`crates/ferroan-region/src/grid.rs` 542–543, each defaulting to 256). A neighbour can have another size. Section 6 records the field copy. `RequestMapBlocks` (911–1050) queues at most 150 requests per agent (975). Past that cap the agent is blocked for `SPAMBLOCKTIMEms`, 30000 (901, 979). The item worker allows `MAX_ASYNC_REQUESTS` of 5 (640, 699).

`MapSearchModule` handles `MapNameRequest` (`MapSearchModule.cs` 93–151). A name shorter than 3 characters, or shorter than 4 when it ends in `#`, sends a closing block and an alert (104–113). Any other name asks the grid service for up to 20 regions (122) and answers `MapBlockReply`.

`GenerateMaptile` deletes the previous terrain and parcel assets, stores a JPEG named `terrainImage_<region id>` with `AssetFlags.Maptile`, and sets `asset.Local` from `LocalV1MapAssets` (`WorldMapModule.cs` 1557–1621). The overlay uses quality 95 (`EncodeSkBitmapToJpeg` 1786–1793). A region with `RegionSizeX` or `RegionSizeY` above `Constants.RegionSize` (256, `Constants.cs` 46) is scaled to that edge before the encode (1585–1604).

The map-image upload module loads when `[Modules] MapImageService` is `MapImageServiceModule` and `[MapImageService]` exists (`MapImageServiceModule.cs` 69–81). ### Dynamic textures

`DynamicTextureModule` registers `IDynamicTextureManager` on every scene (`DynamicTextureModule.cs` 349–355). `[Textures] ReuseDynamicTextures` and `ReuseDynamicLowDataTextures` default false (334–335). When reuse is on, the cache is in memory with a TTL of 24 hours (337–340). There is no `MaxDynamicTextures` key.

The face stores a new texture UUID. The asset is local. A vector drawing is a JPEG 2000 codestream from CoreJ2K (`VectorRenderModule.cs` 469). The URL image path and the blend path store JPEG. `AddDynamicTextureURL` calls `AsyncConvertUrl` and returns `updater.newTextureID` (`DynamicTextureModule.cs` 204–205). That id is still zero when the fetch has not finished. `osSetDynamicTextureData` and the draw helpers that build the command string are P4.S16. This plan is the module those calls enter.

`LoadImageURLModule` filters the URL (`LoadImageURLModule.cs` 108) and reads `[Startup] HttpProxy` and `HttpProxyExceptions` (109–122). It resizes to 32, 64, 128, 256, 512 or 1024 on a side (218–246) and encodes JPEG at quality 100 (263, 270). `VectorRenderModule` reads `[VectorRender] font_name`, default `Arial` (`VectorRenderModule.cs` 99, 222–243). The shipped file leaves that key commented (`RegionServerDefaults.ini` 2142–2144). `GetDrawStringSize` measures with the typeface Skia resolves for the requested family (158–175). Width and height in `extraParams` clamp to 1..2048 and otherwise stay 256 (294–360). The `Image` command uses the same outbound URL filter (231–233), which is P4.32.

### OAR save and IAR

Phase 2 loads an OAR. The save path is `save oar`. Options (`ArchiverModule.cs` 274–303): `-profile` warns and does nothing, `-home` sets `home`, `--noassets` skips assets, `--publish` sets `wipe-owners` (286), `--perm=` sets `checkPermissions`, `--all` saves every region. The path defaults to `region.oar`. The overwrite check is commented out (298–301).

`ArchiveWriteRequest` writes major version at most 1 (`ArchiveWriteRequest.cs` 53–58). Defaults are `SaveAssets` true, no permission filter, and a single region (123–125, 132–145). The control file `archive.xml` is the first member (`ArchiveConstants.cs` 40, `ArchiveWriteRequest.cs` 168–169). Then each region, then assets unless `--noassets` (178–200). A region member skips an object that is deleted, an attachment, temporary, or in transit (`ArchiveWriteRequest.cs` 238). `--perm` also skips an object the estate owner may not archive. `Save` writes region settings, each parcel, a `.r32` terrain member and each object's XML2 (579–627). Paths are `settings/`, `landdata/`, `terrains/` and `objects/` (`ArchiveConstants.cs` 59–75). `--all` writes a `<regions>` manifest of rows and region placeholders, including an empty row and an empty region (`ArchiveWriteRequest.cs` 503–506, 528–568), and prefixes each region with `regions/<dir>/` (180, 581–582). A single-region control file is version 0.8. `--all` writes version 1.0 (432–442).

`--publish` writes `UUID.Zero` for parcel group and owner (`LandDataSerializer.cs` 181, 200–225) and for object group, owner, last owner and rezzer, and for task-inventory owners (`SceneObjectSerializer.cs` 1716–1725, 1918–1942). `-home` writes `CreatorData` when the part's `CreatorData` is empty (`SceneObjectSerializer.cs` 1650–1656, 1907–1911) and rewrites object assets the same way (`AssetsRequest.cs` 227–232). P2.S1's writer (`crates/ferroan-scene/src/xml.rs` `to_xml2` and `to_original_xml`) writes the stored owners. It does not take `wipe-owners` or `home`. The parcel XML in `crates/ferroan-scene/src/parcels/oar/land_xml.rs` reads an archive. It does not write one.

`UuidGatherer` (`Scenes/UuidGatherer.cs` 49) collects object asset ids (`ArchiveWriteRequest.cs` 280). The same pass adds terrain textures, PBR materials, the region environment and parcel media ids (299–338).

[TB198](../TRANQUILLITY_BUGS.md) is a terrain member of length zero when a cell is at or above 4095 m, and that archive then fails to load. The save row owns that gate. What Ferroan writes where the pin writes an empty member is a decision (section 5, item 11). [TB164](../TRANQUILLITY_BUGS.md) is an IAR load that rewrites the object asset and drops `GroupScriptStates`. P4.22 writes no `GroupScriptStates` into object XML. A compare of an archive load does not expect script state the archive carried.

IAR console usage (`InventoryArchiverModule.cs` 111–142): `load iar` takes `-m|--merge`, the user's first and last name, an inventory path, a password and an optional path or URI (120). `save iar` takes `-h|--home`, `--noassets` or `--skipbadassets`, the same identity fields, an optional path, `-c|--creators`, `-e|--exclude`, `-f|--excludefolder`, `-v|--verbose` and `--perm=` (140–141, 458). The default file is `user-inventory.iar` (59). `--home` writes control-file version 1.2. Without it the version is 0.3 (`InventoryArchiveWriteRequest.cs` 591–598). The `userprofiles/` path exists (`ArchiveConstants.cs` 80) and `SaveUsers` would write it (`InventoryArchiveWriteRequest.cs` 501–515), but the call is commented out (463–464), so a save writes no user-profile member. A load that finds the owner logged in pushes the new nodes to that client (`UpdateClientWithLoadedNodes` 322, 370, 593). Asset members use the same `assets/` path as an OAR.

`[AutoBackupModule] AutoBackupModuleEnabled` is false in the shipped file (`RegionServerDefaults.ini` 2899). That module also writes OARs. It is out of this plan.

### Media

### Sound

With no `[Sounds]` section the module is on and `MaxDistance` is 100 (`SoundModule.cs` 68–71). With the section, `Enabled` is true when `Module` equals the assembly file name plus `:SoundModule`, and `MaxDistance` defaults to 100 (75–78). The shipped file sets that module name and `MaxDistance = 100.0` (`RegionServerDefaults.ini` 2902–2907).

`LoopSound` (323–367) writes `Sound`, `SoundGain` and `SoundFlags` (loop bit, master, slave, and queue when the part queues), sets `SoundRadius` to `MaxDistance` when it is 0, then `ScheduleFullUpdate` and `SendFullUpdateToAllClients`. `PlayAttachedSound` (122–160) does not write `Sound`. It sets `SoundRadius` when it is 0, clears `SoundFlags`, adds the queue flag when the part queues, and sends `AttachedSound` to every root presence, with no distance test (156–160). Collision sounds use the material-pair ids in `Scenes/CollisionSounds.cs` (the table starts at 50). `SceneObjectPart.SendCollisionSound` (3132–3157) drops a repeat inside 200 ms, clamps the volume to 0..1, and calls `TriggerCollisionSound` with the owner, the root UUID and the group UUID. `TriggerCollisionSound` (211–228) also skips a presence with `MuteCollisions`. ## 3. Proving equivalence with C#

A row closes on a C# recording, a compiled C# method, a capture, or a store compare. The expected bytes come from that run. Copying a number out of the lines cited above and checking Rust against that copy does not close the row. A Ferroan save loaded by Ferroan does not close an archive row. Pin9 loads the Ferroan archive, and Pin9's own save of the same scene is the other file. Ordinary CI does not start Tranquillity unless an existing tool already does. A live run takes the live lock and uses the bot named in [LIVE.md](../LIVE.md).

What compares exactly: NPC create and delete (presence type, owner, group title, the appearance packet, no grid-user row), chat channel and distance, linkset return codes and the JSON column after a store swap with Pin9, experience cap LLSD and the `/experience` form against Pin9's service, map-block fields, archive member names and the control file, media cap LLSD including the `x-mv:` version, sound packet fields and the radius test, remote-admin success and error structs, and the sim-stats words whose inputs are fixed. A stat that C# leaves at a constant, including `SimPhysicsStepMs` 20 and a `PendingUploads` C# has not filled, matches that constant. C# sends every counter. A Ferroan counter this phase does not measure stays at that constant.

Images compare in two steps. The tolerance is section 5, item 1.

The drawing compares the pre-encode bitmap from a compiled C# call that returns the `SKBitmap`. Flat fills (shaded land, the water colour, a solid command colour) match channel for channel. Every other non-text pixel passes when each channel is within 2 of that bitmap, and fails when any channel differs by more than 2. Text pixels are outside that test. Their budget is a mean absolute error of at most 8 per channel over the glyph pixels, with both sides naming the same font file. `GetDrawStringSize` matches within 2 pixels on that same file.

The encoding is separate. A map JPEG and a URL-image JPEG are Skia's, quality 100 for the terrain tile and the URL image and quality 95 for the parcel overlay (`WorldMapModule.cs` 1793, `LoadImageURLModule.cs` 263 and 270). The upload client re-encodes at quality 95 (`MapImageServiceModule.cs` 289). A vector image is a JPEG 2000 codestream from CoreJ2K (`VectorRenderModule.cs` 469) whose `BuildEncoderConfig` (87–94) is one tile, the irreversible 9/7 wavelet, 5 levels, LRCP, three quality layers, and a raw codestream with no JP2 wrapper. The one-tile reason is the comment at `LegacyMap/MapImageModule.cs` 72–85. `MapImageModule.WriteJpeg2000Image` (146–154) uses a different config, 7 levels and RPCL (93–99), and no caller in `Source/` invokes it. The map rows store JPEG. Both the Pin9 asset and the Ferroan asset are decoded with one decoder. The metric is a mean absolute error of at most 3 per channel. The row does not require the compressed bytes to be identical.

NPC positions that physics integrates use the Phase 3 envelope. The packet identity, the sit refusal and the chat do not use that envelope.

## 5. Questions

Each item has a recommendation. None of them is decided. Items 8 and 10 from the first draft are withdrawn: NPC enablement is the parity in P5.40, and the map image service process is P1.7.

1. **Image tolerance, and the encoders.** C# draws with Skia and stores map tiles and URL images as JPEG, quality 100 or 95 as section 3 says. Vector drawings are JPEG 2000 from CoreJ2K. [D8](../DECISIONS.md) does not allow Skia. [PLAN.md](../PLAN.md) already names tiny-skia, a font crate, and the `j2k` crate. Recommendation: keep those three, and confirm two tolerances. The drawing tolerance compares the pre-encode bitmap from a compiled C# call. Flat fills match channel for channel. Other non-text pixels pass when each channel is within 2, and fail when any channel differs by more than 2. Text pixels are a separate budget: mean absolute error at most 8 per channel over the glyph pixels, both sides naming the same font file. The encoding tolerance decodes the Pin9 asset and the Ferroan asset with one decoder. For JPEG 2000, the codestream is also one tile, 9/7 irreversible, 5 levels, LRCP, 3 layers, and a raw codestream with no JP2 wrapper (`VectorRenderModule.cs` 87–94). The decoded metric is a mean absolute error of at most 3 per channel, for JPEG and for JPEG 2000. The compressed bytes are not required to match. `GetDrawStringSize` matches within 2 pixels on that same font file. Rows: P5.57, P5.57a, P5.58, P5.59, P5.60a, P5.61, P5.61a, P5.62.

2. **Which map generator ships.** The name key defaults to `MapImageModule`, and the shipped file leaves that default in place. `Warp3DImageModule` enables only when the key is set to that name. Recommendation: ship the legacy generator. A Warp3D row is added later, inside this id range with a letter suffix, only if the maintainer wants those images. The Warp3D keys at `RegionServerDefaults.ini` 521–533 stay in the config reader so a file that selects that generator still has them. Rows: P5.57, P5.57a.

3. **Where experience rows are proven.** The region module is a client of the experience service. [P1.12](../../TASKS.md) owns the Ferroan connector and the Ferroan store. P1.0 and P1.1 are done. P1.12 is still to do. Tranquillity's store is MySQL, and a standalone region loads that service in-process. Recommendation: P5.51 enables Pin9's Robust connector on MySQL, and P5.51a through P5.54 prove the region client against that service. Do not build a second store in the region, and do not add a SQLite experience store. The rows are not blocked on P1.12. Rows: P5.51, P5.51a, P5.51b, P5.53, P5.54.

4. **Remote admin exposure.** The shipped file leaves the plugin off and sets the password to a well-known word. Recommendation: stay off unless `enabled` is true, and refuse to bind while the password is empty or still that shipped word. That is a config-compatibility change. The evidence for P5.74 sets its own password. Rows: P5.74. Section 6.

5. **Hypergrid world map.** Every hypergrid grid in the shipped includes sets `WorldMapModule` to `HGWorldMap`, and Phase 1 includes hypergrid. P5.55b is that module. Recommendation: keep the lettered row. Rows: P5.55b.

6. **Linkset account past 131072.** A write is refused only once `BytesFree` is at or below 0. A write that still sees a positive `BytesFree` is stored, and the account is then clamped, so one write can pass 131072 and return success. A later shrinking update of that key is refused because the limit is tested first (`LinksetData.cs` 131–156, 385–391). A script can see the return code. Recommendation: match the pin's return codes, so a script that fills the store sees the same success and the same later refusal. The defect is recorded in section 6. A corrected account, which subtracts the old cost first and refuses a write that would pass 131072, is the alternative. Rows: P5.48.

7. **World-map Y size.** `WorldMapModule.cs` 168 copies `RegionSizeX` into `m_regionSizeY`. Items (385) and the map export (1279) read that field. `MapBlockFromGridRegion` (1137–1138) writes `SizeY` from the grid region's `RegionSizeY`. The grid record has `sizeY` (`crates/ferroan-region/src/grid.rs` 543). Recommendation: set the field from `RegionSizeY`. A square region hides the copy. Rows: P5.55a, P5.56. Section 6.

9. **Where the code lives.** [ARCHITECTURE.md](../../ARCHITECTURE.md) puts map and dynamic textures in `ferroan-modules`. The other modules in this file have no crate named. Recommendation: map and dynamic textures go in `ferroan-modules`. NPCs, linkset data, Experiences, archives, media, sound, remote admin and the stat values stay in the region and scene crates that already hold presence, archives and status. No new crate. Rows: all of section 4.

11. **Record a decision for the TB198 deviation.** [TB198](../TRANQUILLITY_BUGS.md) already assigns the gate to the save row. The pin writes a terrain member of length zero when a cell is at or above 4095 m, and that archive fails to load. A Ferroan member Pin9 can load is a deviation from the bytes the pin writes. [AGENTS.md](../../AGENTS.md) §1 records that kind of deviation as a decision. Recommendation: record the decision, and let P5.64's evidence be Pin9 loading the member Ferroan wrote. The bug is not refiled. Rows: P5.64.

12. **How Ferroan treats a null parent group on a sound.** Section 6, TB223. `PlayAttachedSound` evaluates both sides of a non-short-circuit or. `TriggerSound` and `TriggerCollisionSound` use `ParentGroup` with no test. Recommendation: record the pin's throw in the fixture, and skip the send when the group is null. The alternative is to throw where the pin throws. Rows: P5.73a, P5.72.

13. **How many scenes the experience module keeps.** Section 6, TB227. The module stores one scene, the last region added, and `RemoveRegion` assigns its parameter to null. Recommendation: one scene per region, so caps and estate lookups follow the region that registered them. The alternative is the pin's single field. Rows: P5.51b, P5.52a.

14. **Whether remote admin logs the console command.** `XmlRpcConsoleCommandMethod` (`RemoteAdminPlugin.cs` 1969–1981) logs that a command request arrived and that it completed. The command text is not in those lines. Recommendation: keep the pin's two log lines and leave the command text out of the log. The alternative is to log the command when remote admin is on. Rows: P5.77b.

15. **Whether a linkset pattern match is bounded.** `FindLinksetDataKeys`, `LinksetDataCountMatches` and `LinksetDataMultiDelete` (`LinksetData.cs` 208, 257, 280) build `new Regex(pattern, RegexOptions.CultureInvariant)` from a script-supplied pattern, with no match timeout. [D131](../DECISIONS.md)'s 250 ms is the `os` regex calls, P4.34 through P4.34f, and those calls do not cover this pattern. Recommendation: add a match timeout, record it as a new [LIMITS.md](../LIMITS.md) id when P5.49 lands, and keep the pin's unbounded match in the fixture. The alternative is to match the pin and leave the match unbounded. Rows: P5.49.

16. **How Ferroan reports a dynamic-texture URL whose prim was deleted.** Section 6, TB228. `DataReceived` (`DynamicTextureModule.cs` 477–481) enters the error path when `part` is null and then reads `part.ParentGroup.RootPart.AbsolutePosition`, `part.Name` and `part.UUID` for the say. Recommendation: record the pin's throw. When the part is gone, send the same error sentence as a say at the region's zero position, with an empty name and the zero id, and do not read `ParentGroup`. The alternative is to throw where the pin throws. Rows: P5.60a.
