## Phase 1: Grid services

Gate: each Rust service runs behind a C# grid in the live harness. A C# region using it passes the same scenarios as with the C# service. The C# service reads what the Rust service wrote, and the Rust service reads what the C# service wrote, on the same database and files, so an operator can switch back at any time. The scope is in the [plan](docs/PLAN.md).

The three asset backends are those Tranquillity ships (18 November 2026, `8583218`): `AssetService` on SQLite, MySQL and PostgreSQL (`AssetStore`); `XAssetService` on MySQL and PostgreSQL (`XAssetStore`); and FSAssets on MySQL and PostgreSQL plus a file tree (`FSAssetStore`). `ferroan-robust` serves all three behind the same asset HTTP routes, chosen by `[AssetService] LocalServiceModule` as in C#.

- Route by route, the HTTP request and reply forms match fixtures captured from the C# service at the pin (dates and generated ids folded).
