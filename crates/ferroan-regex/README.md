# ferroan-regex

`parse` follows `RegexParser.Parse` for `RegexOptions.None` on the .NET 10.0.14 runtime ([D131](../../docs/DECISIONS.md)). A pattern that runtime accepts parses. A pattern it rejects produces the same `RegexParseException` text, including the UTF-16 offset.

A pattern that parses carries concatenation, alternation, quantifiers and capturing groups. `group_numbers` and `group_names` are `Regex.GetGroupNumbers` and `Regex.GetGroupNames`. Group 0 is the whole pattern. `enumerated_groups` is the sequence `foreach (Group g in match.Groups)` walks. Its length is the slot count. Index `i` is that declared group when `i` is one of the numbers, and a hole otherwise, so a sparse number is never visited. `osMatchString` appends `Value` and `Index` only when `Success` is set. A hole is never successful. A `{0}` quantifier drops its child from the tree and keeps the slot. The character-class set, backreferences, lookaround matching, replacement and the 250 ms timeout are later rows. A null pattern is not representable: the script wrapper turns one into an empty pattern before it compiles.

Three Ferroan bounds are not .NET messages. `regex.pattern-chars` refuses a pattern longer than 65,536 UTF-16 code units before the walk starts. `regex.class-depth` allows 64 nested class subtractions and refuses the 65th. The outer class is not a subtraction. `regex.tree-depth` allows 64 nodes on the deepest path, counting the implicit group 0 and the leaf, and refuses the node that would make 65. The check runs before that node is built. All three report through [docs/LIMITS.md](../../docs/LIMITS.md).

The files `src/lib.rs`, `src/parse.rs` and `src/names.rs` are ported from `RegexParser.cs` and `RegexCharClass.cs` at dotnet/runtime tag `v10.0.14`. They keep the MIT notice. The C# source is not copied. [NOTICE.md](../../NOTICE.md) records the origin.

[fixtures/regex-parse](../../fixtures/regex-parse/README.md) holds the corpus, the SHA-256 digest and one full message for each error kind. [fixtures/regex-groups](../../fixtures/regex-groups/README.md) holds the declared group numbers and names. [fixtures/regex-enumerate](../../fixtures/regex-enumerate/README.md) holds a few successful matches and the groups `Match.Groups` actually yields. `tools/regex-oracle` runs `new Regex` on .NET 10.0.14 and writes those files. `cargo test -p ferroan-regex` rebuilds the canonical texts and checks the digests, the literal messages, the parse tree and the enumeration.
